# MCP 接入

[English](./en/mcp.md)

让 Claude Code、Codex、Cursor 这类 AI 助手通过面板操作你的服务器。

服务器的密码和私钥始终留在面板里，AI 拿到的只是一个令牌。它能碰哪几台机器、能不能执行命令，都由你发令牌时决定，随时可以收回。

入口：顶部设置 → 「MCP 接入」。需要闪电权益。

---

## 第一步：换正式证书

**Claude Code 和 Codex 连不了自签证书的面板。** 面板默认就是自签证书，不换的话 AI 连不上，而且报错里一般看不出是证书的原因。

在「设置 → SSL 证书设置」里开启 ACME，填服务器 IP 或域名都行，见 [SSL 证书配置](./webssh.md#ssl-证书配置)。已经用反向代理挂了正式证书的可以跳过这步。

没换证书时 MCP 页面顶部会有提示。

---

## 第二步：发令牌

点「新建令牌」，填四项：

| 字段 | 说明 |
|------|------|
| **名称** | 自己认得出来就行，比如 `claude-code-laptop` |
| **权限** | 只读或可执行，见下表 |
| **有效期** | 到期自动失效。也可以选「永不过期」，但这样的令牌泄露后会一直能用，直到你手动撤销 |
| **授权主机** | 选「指定主机」，勾选这个令牌能操作哪几台机器，没勾的碰不到；列表是空的话，先去主机面板保存几台。或者选「全部主机（含以后新增）」，见下文 |

| 权限 | 能做什么 |
|------|---------|
| **只读** | 查看有哪些机器、读取文件，不能执行命令 |
| **可执行** | 执行命令、读写文件，相当于把这个 SSH 账号交给了它 |

「全部主机（含以后新增）」：令牌能操作面板里所有保存了登录凭据或记录过指纹的主机，以后新加的也自动算进去，不会再问你。云同步自动添加、还没连过的主机不在其内，需要的话改用「指定主机」单独勾。只在完全信任这个 AI 时用。

---

## 第三步：配置 AI 客户端

令牌生成后，同一个页面会给出三份配好的内容（之后也可以在令牌列表里点「显示」再看）：

- Claude Code
- Codex CLI：分两段，`export` 那一行加到 `~/.bashrc` 或 `~/.zshrc`（新开终端才生效），另一段写进 `~/.codex/config.toml`
- Cursor 和其他客户端用的 JSON

复制对应的那份，贴进你的 AI 客户端配置里就能用了，地址和令牌都已经填好。

配好之后直接跟 AI 说"看看某某服务器的磁盘占用"之类的就行。执行时间长的命令它会放到后台跑，稍后再来取结果。

## 安全须知

**1. 给 AI 单独建一个没有 sudo 的账号。**

能执行命令，就能在服务器上给自己留后门。别把 root 或你自己日常用的账号给它。

在服务器上建一个专用账号，并把它的公钥放到它自己改不了的地方：

```bash
useradd -m -s /bin/bash aiagent
mkdir -p /etc/ssh/keys
echo "ssh-ed25519 AAAA...你的公钥" > /etc/ssh/keys/aiagent
```

然后在 `/etc/ssh/sshd_config` 末尾加上这两行，只对这个账号生效：

```
Match User aiagent
    AuthorizedKeysFile /etc/ssh/keys/%u
```

**不要**把 `AuthorizedKeysFile` 直接写在外面、不带 `Match User`，那样所有账号都会改从这个目录找公钥，你现在登录用的账号（root、ubuntu、opc 等）原来的公钥都会失效，可能把你自己锁在服务器外面。

改完先执行 `sshd -t` 检查有没有写错，再重启 sshd。当前连接先别断，新开一个窗口确认你平时用的账号和 aiagent 都还能登录。

在面板里用 aiagent 保存主机，发令牌时只勾这台。

**2. AI 看到的内容会发给 AI 服务商。**

它读了什么文件、命令输出了什么，都会传到 AI 服务商那里。别让它去读私钥、带密码的配置文件、数据库备份。只读权限挡不住这一点 —— 只读只是不能改，不是不能看。

## 管理令牌和查看记录

令牌列表里能看到每个令牌授权了几台机器、还剩多久到期、最近一次什么时候用过。

| 操作 | 说明 |
|------|------|
| **显示** | 再看一次令牌和配好的配置内容 |
| **续期** | 有效期从现在重新算。令牌不变，AI 客户端的配置不用改 |
| **主机** | 修改令牌能操作的主机，令牌不变，AI 下一次调用就按新范围。移出去的主机上正在跑的任务会被断开 |
| **撤销** | 立刻生效，AI 马上失去访问权限，**它正在跑的任务也会一起停掉** |

下面的「调用记录」里能看到 AI 每一次做了什么，也可以清空。
