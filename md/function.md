## Web 云管理面板

### Oracle Cloud

- [x] 实例管理（创建、快捷开机、强开 ARM、启动、关机、重启、终止、重装系统、升降配、改名、修复）
- [x] 快速配置（AMD 微型 1C/1G、ARM A1 2C/12G 一键填好参数）
- [x] 用现有启动盘开机
- [x] 页面直接显示开机结果
- [x] 网络管理（换 IP、附加 IPv4 / IPv6、保留 IP、删除 IP）
- [x] 硬盘管理（扩容、提升 IO、分离、附加、删除）
- [x] 卸下来的启动盘挂回实例
- [x] A1 配置体检 / 降配（批量检查 ARM 是否超出免费额度并降回，不会自动删实例）

- [x] 概览（成本、流量、订阅、配额）

- [x] 按账号配置 API 出站代理
